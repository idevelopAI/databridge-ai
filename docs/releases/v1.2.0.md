## DataBridge AI 1.2.0

This release strengthens the local Text-to-SQL workflow with:

- deterministic clarification before model calls
- column-level privacy policy and direct-value masking
- PostgreSQL query-plan cost gating
- privacy-safe metrics and local reviewed feedback
- a 40-case bilingual evaluation with 12 unsafe SQL cases
- a one-command recorded demo that needs no API key

The committed recorded-mode report measured 40/40 result-equivalent executions,
12/12 unsafe-query rejections, 1 ms p50 latency, 3 ms p95 latency, and zero model
tokens. Recorded fixture replay is not presented as live model accuracy.

### Container Images

```bash
docker pull ghcr.io/idevelopai/databridge-ai-backend:1.2.0
docker pull ghcr.io/idevelopai/databridge-ai-frontend:1.2.0
```

Both images include signed GitHub build-provenance and SBOM attestations. SPDX
SBOMs, Trivy reports, and SHA-256 checksums are attached to this release.

The supplied Compose setup remains local-only and binds services to loopback by
default. No public hosted instance is part of this release.
